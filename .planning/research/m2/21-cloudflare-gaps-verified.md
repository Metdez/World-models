## Recommendation for Suspension Lab

- Static Assets are free and unlimited per Cloudflare docs; keep `run_worker_first: ["/api/*"]` only. The 100k/day Free budget then applies to API/WS upgrade calls only. [VERIFIED]
- DO rooms: use `ctx.acceptWebSocket` (Hibernation API) so idle rooms bill no duration; incoming WS messages bill 20:1 and outgoing are free, so a presenter at 10-20 Hz is affordable on Free. Correct the earlier "WS counts 1:1" assumption in doc 16. [VERIFIED]
- Rate limiting: add the binding with `delta` weighting, but test on Free first; keep a D1/DO daily counter as the hard cap. [UNVERIFIED on Free]
- AI explainer: use `@cf/google/gemma-4-26b-a4b-it` (listed, tools yes, 256k, 9091/27273 neurons per M). Do not use qwen3-30b, llama-3.1-8b-fp8, llama-3.2-*, kimi-k2.6/2.7, glm-5.2/5.3-flash: deprecated 2026-11-20 (HTTP 410). Template-first fallback must handle 410 and 429. [VERIFIED]
- Turnstile: token valid 300 s, single-use but eventually consistent; verify once per save and keep your own nonce. [VERIFIED]
- D1: 5M reads, 100k writes per day, 500 MB per Free DB, 5 GB per account, 2 MB per row. KV: 100k reads, 1k writes. Both sufficient for share links at event scale. [VERIFIED]
- Access: Free to 50 users; confirm no card prompt at onboarding. [VERIFIED limit; card UNVERIFIED]
- AI Gateway: new accounts log via Workers Logs (Free 200k events/day, 3 days); skip logging prompts or disable payload collection (`cf-aig-collect-log-payload: false`). [VERIFIED rule]
- Share-card images: do not rely on Browser Run for WebGL; capture client-side. [WebGL UNVERIFIED]
- R2: assume a payment method is required; stay on D1 (<=64 KB blobs) as planned in doc 15. [UNVERIFIED, docs say checkout flow]
- Optional cheap wins from the Jul-Nov launches: Workers Logs/Traces on Free, KV Instant for presets, Billable Usage API for event-day spend watch.
- Risk: my month-by-month coverage of the global changelog is incomplete; there may be smaller Free-tier changes in Jul-Oct not captured.
