# 01-04 PLAN — Placeholder renderer, end-to-end smoke test, first deploy

**Wave** 3 · **Depends** 01-02, 01-03 · **Parallel with** phase-2 executors (02-01/02/03; disjoint files)

## Objective
The app shows a moving placeholder scene in WebGL 2: `renderer` provides `RENDER` (WebGLRenderer, Y-up scene,
camera, resize, CSS2D label layer, `stats()`, `compile()`), draws the track centreline from
`sim.current.track.toWorld` and a box + wheel cylinders posed from POSE fields via `simToThree`, and chases the car
until a `CAMERA` service exists. `debug` shows stats-gl with `?debug=1`. A Playwright smoke spec proves boot, zero
errors and a non-blank canvas. First live deploy to Cloudflare + live smoke + production e2e.

## Owned files
`src/features/renderer/**`, `src/features/debug/**`, `tests/e2e/smoke.spec.ts`, `tests/e2e/helpers.ts`
(+ this PLAN and the SUMMARY).

## Tasks
1. **Renderer + placeholder.** `renderer/index.ts` (service, resize via ResizeObserver, CSS2DRenderer in `#stage`,
   pixel ratio = 1 in e2e else `min(devicePixelRatio, preset.maxPixelRatio)`, stats EMA), `renderer/placeholder.ts`
   (track line, body box, wheel cylinders rebuilt on `sim:vehicle`, hemisphere light, chase camera when no CAMERA).
   No allocation in `update()`. A failing WebGL context throws in `init` → kernel fatal overlay.
2. **Debug + e2e.** `debug/index.ts`: stats-gl attached to the renderer (patch restored on dispose).
   `tests/e2e/helpers.ts`: `captureConsole`, `waitForReady`, `canvasVariance` (element screenshot decoded in-page).
   `tests/e2e/smoke.spec.ts`: `/?e2e=1` ready ≤ 20 s, zero `__app.errors` and console errors, renderer stats > 0
   draw calls, canvas non-blank; `?e2e=1&paused=1&t=5` + `advance(1)` moves lapTime by 1 s (± SIM_DT);
   `?debug=1` mounts stats-gl.
3. **Deploy.** `npm run deploy` (env credentials), `npm run smoke:live`, `PLAYWRIGHT_BASE_URL=<live> npx playwright
   test tests/e2e/smoke.spec.ts`; record binding outcome. If a binding is rejected: stop, report, no wrangler edit.

## Verification
`npm run typecheck` (own files clean) · `npm run lint:deps` · `npm run build` · `npm run e2e` ·
`npm run deploy` · `npm run smoke:live` · production e2e smoke · screenshot of the placeholder scene.
