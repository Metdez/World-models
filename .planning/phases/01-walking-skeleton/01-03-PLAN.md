# 01-03 PLAN — Worker health/time, asset pipeline, live smoke script

**Wave** 2 · **Depends** 01-01 · **Parallel with** 01-02 (disjoint files)

## Objective
The Worker answers `/api/health` and `/api/time`; `npm run build` turns `assets-src/**` into content-hashed files plus
`public/asset-manifest.json` with attributions (fails on a missing attribution, a broken car hierarchy or a file
> 24 MiB); `scripts/smoke-live.mjs` checks a deployed (or previewed) site per ARCHITECTURE §13. No deploy.

## Owned files
`worker/routes/health.ts`, `worker/routes/time.ts`, `scripts/build-assets.mjs`, `scripts/smoke-live.mjs`,
`assets-src/ATTRIBUTION.json`, `tests/worker/health-time.test.ts`, `tests/scripts/build-assets.test.ts`
(+ this PLAN and the SUMMARY).

## Tasks
1. **Routes + tests.** `GET /api/health` → `HealthResponse` (`version` = `env.APP_VERSION`), `GET /api/time` →
   `TimeResponse`, both `Cache-Control: no-store`. Test with `app.request()` from `worker/index.ts` and a fake env.
2. **Attribution + pipeline + tests.** Verify every source file (Poly Haven md5 via API, Kenney audio sha256 vs a
   fresh `git clone` of KenneyNL/Starter-Kit-Racing + its README licence text, DB11 sha256 vs the GitHub mirror and
   its embedded `asset.extras`); write `ATTRIBUTION.json`. `build-assets.mjs` exports `buildAssets({ srcDir, outDir })`
   per §11: attribution coverage (and no stale entries), glb = dedup + prune(keepLeaves) + meshopt, then re-read and
   assert every named source node survives and ≥ 4 nodes match `/wheel/i`, `/caliper/i`, `/brakedisc/i`; other files
   copied; `<dir>/<base>.<sha256-8>.<ext>`; manifest with attributions; FAIL > 24 MiB, WARN initial set > 12 MB.
   Tests use temp dirs: happy path (hash names, manifest), missing attribution fails, size guard fails, glb missing
   wheel nodes fails, real DB11 keeps its nodes.
3. **Smoke script + verify.** `smoke-live.mjs [baseUrl]`: `/` 200 with `#stage`, `/api/health` ok + version,
   `/api/time` within 5 s, `/asset-manifest.json` 200, first asset 200 with `immutable`. Run it against local
   `vite preview`; `npm run check`, `npm run build`, `wrangler deploy --dry-run`.

## Verification
`npm run check` · `npm run build` (manifest summary printed) · `node scripts/smoke-live.mjs http://localhost:4173`
against `vite preview` · `npx wrangler deploy --dry-run`.
