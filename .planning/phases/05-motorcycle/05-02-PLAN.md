# 05-02 PLAN — Procedural cafe racer + moto suspension visuals

**Objective:** a Thruxton-style cafe racer `VehicleVisual` built entirely from code (no asset), and the `moto-planar`
`SuspensionVisual` for the three presets (RSU fork + gaiters + twin shocks; USD gold fork + linkage monoshock with
rocker/dog-bone; Telelever A-arm + single-sided swingarm). Driven only by contract POSE fields; built on `src/kit3d`.

**Owns:** `src/features/motorcycle/visual/**`, `src/features/motorcycle/parts/**`,
`tests/features/motorcycle-visual.test.ts`, `tests/fixtures/05-02-moto-frame.ts`. Not `motorcycle/index.ts` (05-03).

## Split of responsibilities (no contract change)
- Vehicle visual (`visual/`): frame, engine, tank, seat + hump, exhausts, side panels, tail light, rear-sets, both
  wheels (posed from `wheelPosition`/`wheelRotation`, spun by `spin`), chain (front sprocket → rear sprocket).
  Body posed from `bodyPosition`/`bodyRotation` (the sim's lean is about the vehicle-frame origin on the ground,
  i.e. the contact line). X-ray: one shared dither uniform + additive fresnel ghost (as the DB11).
- Suspension visual (`parts/`): head tube + chassis mounts, steering assembly (yokes, bars, clip-ons, bar-end
  mirrors, headlight, clocks) rotated about the steering axis by the front corner `steer`, fork (sprung/unsprung
  halves, gaiters), front discs/calipers/fender, Telelever A-arm + coil-over, swingarm (twin or single-sided),
  twin shocks / monoshock + rocker + dog-bone, rear disc + caliper. Points are read by name from `pointOrder`
  (hidden until the frame carries them); planar parts rotate in the body x–z plane.
- Materials: palette textures (one draw per rigid body), deep clearcoat paint (physical), chrome/brushed metal,
  rubber; part colours via `COMPONENT_COLORS` (used as sRGB, as 03-04).
