# 04-02 — HUD controls + loading + credits

**Objective:** the minimal premium HUD (research 14 D5, tokens only) that makes the suspension swap ONE click
(or 1/2/3), plus view control, vehicle-class toggle, fullscreen, time controls (pause / slow-mo 0.25× / Live),
the honest amplification chip, the UI-01 keyboard map, the loading overlay (weighted progress, hides on
`app:ready`) and the credits panel (manifest attributions + `code-credits.ts`), mirrored in a complete CREDITS.md.

## Files (owned)
- `src/features/controls/**` — `index.ts` (feature wiring), `keys.ts` (pure key → store patch), `segmented.ts`
  (radiogroup, roving tabindex, sliding thumb), `loading.ts` (pure progress + overlay), `icons.ts`, `controls.css`
- `src/features/credits/**` — `index.ts` (panel), `code-credits.ts` (constant), `text.ts` (pure attribution text),
  `credits.css`
- `CREDITS.md`, `tests/features/controls.test.ts`, `tests/features/credits.test.ts`, `tests/e2e/04-02-controls.spec.ts`

## Layout (1280×720 … 1920×1080; big screens zoom the HUD ×1.25)
- Top-left: vehicle tag (wordmark label, vehicle name, "Representative parameters · Credits").
- Top-centre: amplification chip, only while `amplification ≠ 1`: "Motion ×2.5 · values true scale" + "True scale".
  Stays visible when the HUD is hidden (honesty).
- Top-right: time group (Live / Rejoin live, pause, 0.25×) · vehicle toggle (hidden with one class) · fullscreen · ?.
- Bottom-centre: suspension segmented control (primary, full labels) + one-line descriptor of the selection.
- Bottom-right: view segmented control (Follow · Explore · Close-up).
- Bottom-left left free for telemetry (04-03), engineer pill (06-02) and live-lab (06-01).
- `?` opens a shortcut card (rows are tappable actions; includes Credits). HUD hides on H and during attract.
