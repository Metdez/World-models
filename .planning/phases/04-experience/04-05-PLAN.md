# 04-05 PLAN — HUD layout + integration pass (gap closure, not in ROADMAP)

## Objective
Turn the HUD pieces that 04-01..04-04, 06-01, 06-02 and 06-04 built in parallel into one coherent, minimal screen in
which the 3D world is the hero. Every element gets one home, all follow one scale rule, nothing overlaps at 1280×720
and 1920×1080 (follow, close-up, `?screen=1` with a room, engineer open), and the integration loose ends noted in
their SUMMARYs are closed.

## Layout (research 14 D5, HUD px before the big-screen zoom)
- Left column (x = margin, 316 px wide): vehicle tag (fixed height) → Live Lab as one slim line → presenter join
  card (screen only) … telemetry card → "Ask the engineer" pill (bottom). The engineer panel is capped at the column
  width; the telemetry card hides while it is open (as before).
- Centre: amplification chip (top), debug stats under it (`?debug=1`), insight caption above the suspension control
  (capped so it can't reach the columns).
- Right column: time/display groups (top), camber trace, poll (above the view control), view control (bottom).
- One scale rule: ×1.25 at ≥1600×860, ×1.6 at ≥2400×1300 for every HUD piece. Shared layout lengths live as
  custom properties in controls.css (`--sl-hud-*`), consumed with fallbacks.
- Close-up: the wheel is the hero — telemetry collapses to g-g + two numbers, the far axle's construction is hidden,
  x-ray stays on (X is explained, not silently ignored).
