# 04-04 PLAN — Teaching overlays

**Objective:** the Engineer layer (`store.overlay === 'engineer'`; entering close-up switches it on) makes the
geometric difference between suspension types visible: live front-view construction per axle, a ghost rest pose,
load arrows / contact patches, and a camber-vs-travel trace that keeps the previous suspension faint. Every drawn
thing comes from live POSE fields / `sim.restPose()` / `sim.kinematics()`; numbers shown are TRUE values.

**Owns:** `src/features/teaching-overlays/**`, `tests/features/teaching-overlays.test.ts`,
`tests/e2e/04-04-overlays.spec.ts`.

## Tasks
1. **Construction lines + ghost pose** (`lines.ts`, `construction.ts`, `index.ts`)
   - One fat-line batch (three `LineSegments2`, preallocated interleaved buffer, `instanceCount` = used) drawn twice
     (dark casing + colour) on top of the scene; a second thin batch for the ghost.
   - Per corner: contact patch → IC → (RC) force line, IC ring; arm-plane ∩ front-view-plane lines from each A-arm
     (two distances sharing a member) and strut (plane ⟂ strut axis through the top mount) to the IC (car only,
     derived from the definition's constraints — no id branching). Per axle: RC ring + short trail stored in the body
     frame. Far/at-infinity ICs: length clamp + colour fade; non-finite values skipped (never NaN in buffers).
   - Ghost: `restPose()` linkage skeleton (constraint links, upright polygon, spring) + ghost tyre outline placed by
     the rigid upright transform F_rest·F_live⁻¹ applied to the live wheel pose. Motorcycle: rest-point markers.
2. **Camber trace + load arrows / patches** (`trace.ts`, `teaching-overlays.css`)
   - Canvas panel (≤ 30 Hz): per axle camber-vs-travel curve from `kinematics()`, previous suspension's curve faint
     (copied on `sim:suspension`), moving L/R dots at TRUE travel/camberBody, TRUE RC height + camber numbers drawn
     with a zero-allocation digit renderer. Motorcycle: motion ratio vs travel.
   - Load arrows (length ∝ load) + contact-patch rings coloured by grip use (model), warn > 1, in the main batch.
3. **Tests + e2e** — node: geometry helpers (plane intersection, clamp, no NaN with parallel arms / IC at 1000 m),
   arm lines meet the sim IC for DW/MacPherson, 4-corner sim frames + a 2-corner motorcycle frame, zero allocation
   in `update()`; e2e: engineer overlay on a private build, front-view screenshots per type + trace after a swap.
   Stretch part labels: skipped unless time remains.
