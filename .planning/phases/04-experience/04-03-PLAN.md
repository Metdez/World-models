# 04-03 — Telemetry panel + insights

**Objective:** a small, premium bottom-left telemetry card (research 14 D5 "TelemetryCard") and a one-line
contextual insight caption with a delta chip on suspension swap. Every number comes from the live
`TelemetryFrame` / `sim.kinematics()` (TRUE fields only, never POSE), formatted with `src/ui/format.ts`.

## Files (owned)
- `src/features/telemetry-panel/**` — `index.ts` (feature), `history.ts` (pure ring + per-suspension lap record),
  `draw.ts` (zero-alloc canvas painters), `telemetry-panel.css`
- `src/features/insights/**` — `index.ts` (feature), `rules.ts` (pure rule engine + digit-free templates),
  `lap-record.ts` (pure same-spot comparison for the delta chip), `insights.css`
- `tests/features/telemetry-panel.test.ts`, `tests/features/insights.test.ts`, `tests/e2e/04-03-hud.spec.ts`

## Design decisions
- Placement: card bottom-left (D5), stacked above the existing "Ask the engineer" pill; collapses while
  `store.engineerOpen` (the engineer panel grows upward into the same column) or `!hudVisible`. Caption
  bottom-centre above where 04-02's suspension control sits. Narrow screens: g-g + roll only.
- Card: one DPR-aware canvas (g-g with 1.5 s trail; 2×2 / 1×2 corner cluster mirroring the plan view: camber arc
  with static tick, travel bar between the kinematic travel limits, load square = load / static corner load);
  six DOM numbers max (lateral g, roll, per-corner camber), sparkline with metric tabs Camber | Travel | Load for a
  selectable corner. Ghost = the previous suspension's trace at the SAME track position (lap record binned by s),
  never "the previous seconds" (which would compare different road). 30 Hz ticker driven by sim time.
- Insights: rules keyed by section phenomenon + `sim:event`, condition hysteresis (re-arm below 80 % of the
  trigger), ≤ 1 caption per 8 s, 6 s visible, per-rule cooldown, aria-live polite, emits `insight:shown`,
  silent during attract. Templates contain no digits; placeholders filled from the frame via `format.ts`. No
  template ranks a suspension type.
- Delta chip: on `sim:suspension`, after 1 s settle, previous suspension's value at the same track position (lap
  record) → new value; falls back to before-swap vs after-settle only inside a steady section. Metric by
  phenomenon (camber / travel / pitch), corner = largest |Δ|.
- Tradeoff bars (stretch): skipped unless time remains.
