# 06-02 PLAN — AI Race Engineer

**Objective:** `POST /api/engineer` answers a visitor's question in 1–3 plain sentences grounded in curated fact
cards (which agree with the measured simulation, 02-02/02-04) and the client's live telemetry, with at most two
whitelisted, client-executed actions. Any number not in the telemetry, any model error/timeout/quota, or rate
limiting yields a labelled rule-based answer. A small "Ask the engineer" overlay (input, three section-dependent
chips, "Why did it do that?") renders the answer as a caption card and executes actions only through the store /
bus events of the contract. ARCHITECTURE §12.5, ROADMAP 06-02.

**Owns:** `worker/engineer/**`, `worker/routes/engineer.ts`, `worker/schemas/engineer.ts`, `src/features/engineer/**`,
`tests/worker/engineer*.test.ts`, `tests/fixtures/06-02-*.json`, `tests/e2e/06-02-engineer.spec.ts`.

## Tasks
1. **Spike + normaliser + number check.** Real REST calls to the primary and fallback model (done before coding:
   OpenAI chat-completion shape `choices[0].message.{content, tool_calls[].function.arguments:string}`), sanitized
   fixtures `tests/fixtures/06-02-ai-response-{tools,text,glm}.json`; `worker/engineer/model.ts` (normalise +
   run with timeout and fallback model), `worker/engineer/numbers.ts`; tests against the fixtures.
2. **Grounded worker route.** `facts.ts` (common + per-suspension cards, digit-free, incl. "what the model does
   not capture"), `prompt.ts`, `fallback.ts` (phenomenon × suspension), `schemas/engineer.ts` (zod request +
   action union), `routes/engineer.ts` (400 / 429 busy / model → validate actions ≤ 2 → number check → fallback,
   no-store). Route tests with fake `AI` and `RL_ENGINEER`.
3. **Live evaluation.** `tests/worker/engineer-live.test.ts` (skipped unless `ENGINEER_LIVE=1` + credentials):
   ~10 representative questions through the real prompt builder + REST API + the same post-processing; iterate
   the prompt/cards; transcript goes into the SUMMARY.
4. **Client overlay + e2e + deploy.** `src/features/engineer/` (snapshot ring buffer at 10 Hz, event label,
   payload builder, chips, local rule-based answer, dispatcher, `x-client-id`), e2e with `page.route` mocks
   (model answer with actions, 429 → local labelled answer), `npm run check`, `npm run build`, deploy, live
   endpoint checks.

## Verification
`npm run check`, `npm run build`, `npx playwright test tests/e2e/06-02-engineer.spec.ts --trace off`,
`ENGINEER_LIVE=1 npx vitest run tests/worker/engineer-live.test.ts`, live `curl` against the deployed endpoint.
