# 06-04 PLAN — Presenter remote + poll + remote page

**Objective:** at an event the big screen (`?screen=1`) shows a room code + QR; the presenter scans it and gets a
phone remote (`/remote.html?room=CODE#k=KEY`) that drives the screen in real time; audience phones (`/r/CODE`) get a
vote panel whose live bars show on the screen. Worker side (06-01) is frozen; protocol gaps are reported, not patched.

**Owns:** `src/features/presenter/**`, `src/features/poll/**`, `src/remote/**`, `remote.html`,
`tests/features/presenter.test.ts`, `tests/e2e/06-04-presenter.spec.ts`.

## Tasks
1. **Presenter feature (screen).** `apply.ts` (pure): seq-ordered `ctl` diff → ordered store patch (vehicle before
   suspension, suspension validated against the vehicle's registry entry), section jump → `sim:seek-to`, cues →
   `camera:focus` / seek + `room:cue`. `qr.ts`: `uqr.encode` → one SVG path (no innerHTML). Card top-right (below the
   D5 icon row): presenter QR (`#k=` fragment) until the first host `ctl`, then the audience QR (`/r/CODE`), with a
   toggle and a collapse. Only on `role === 'screen'`.
2. **Poll feature.** Screen: live bars card on the right above the D5 segmented controls (open → live, closed →
   "final" for 20 s, then hidden). Viewer in a private room: same card with tappable options (vote chip).
3. **Remote page** (`src/remote/**`, no three.js): own partysocket connection (host with `#k=`, stored in
   sessionStorage and stripped from the address bar; audience otherwise), host panel (vehicle, suspension, view,
   x-ray, slow-mo, amplification, section grid incl. replay cue, camera cues, poll open/close/run winner) and audience
   vote panel; mobile layout with `src/ui` tokens, ≥ 48 px targets, works at 360×640.
4. **Tests.** `tests/features/presenter.test.ts` (ctl ordering/diff, cue mapping, catalogue, poll shares/winner, host
   key parsing); `tests/e2e/06-04-presenter.spec.ts`: screen + host phone + audience phone against the real Room DO
   (vite preview on a private port), screenshots, remote bundle contains no three.js, `/remote.html` redirect keeps
   `?room=`.

## Verification
`npm run check`; private `npx vite build --outDir <scratch>` + `vite preview` on a private port; the 06-04 spec with
`--trace off`; screenshots inspected.
