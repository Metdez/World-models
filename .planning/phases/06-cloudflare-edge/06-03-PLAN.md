# 06-03 PLAN — Anonymous analytics

**Wave** 1 (phase 6) · **Depends** Phase 4 (started early: only the store/bus contracts are needed) ·
**Parallel with** 03-01, 03-03, 06-01, 06-02 (disjoint files)

## Objective
`POST /api/event` validates the frozen `AnalyticsEvent` union (net.ts) and writes one Analytics Engine data point per
event (`blobs:[type, a, b]`, `doubles:[n]`, `indexes:[type]`) → 204; a missing `STATS` binding is a silent no-op.
Body ≤ 2 KB, a single event or a batch of ≤ 8 (sendBeacon-friendly: any content type, parsed as JSON text);
unknown/oversized/free-text payloads → 400; a per-isolate fixed-window limit per client address → 429 (the address is
held in memory for ≤ 60 s, never written or logged). The `analytics` feature queues events from the store and sends
them in batches via `navigator.sendBeacon` (fetch keepalive fallback); every failure is swallowed. Off with DNT, GPC,
`?e2e=1`, and `?features=-analytics` (kernel).
