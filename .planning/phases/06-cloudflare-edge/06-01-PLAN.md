# 06-01 PLAN — Room Durable Object + Live Lab

**Objective:** the hibernating `Room` Durable Object (ARCHITECTURE §12.4) behind `POST /api/rooms`, `GET /ws/:code`,
`GET /r/:code`, and the `live-lab` client feature: everyone on the same lap via server-time sync
(`clock.setOffset` → kernel live clock §6.5), plus a small presence readout ("N in the lab" + live suspension
distribution). Viewers send only `pick` (vehicle + suspension) changes, never positions. Offline / `?e2e=1`: the
ROOM service exists with `connected: false` and the readout is simply absent.

## Files (owned)
`worker/room.ts`, `worker/room-logic.ts`, `worker/routes/rooms.ts`, `worker/schemas/room.ts`,
`src/features/live-lab/**`, `scripts/smoke-room.mjs`, `tests/worker/room*.test.ts`,
`tests/features/live-lab*.test.ts`, `tests/e2e/06-01-live.spec.ts`.

## Tasks
1. **Schemas + pure room logic** — zod schemas for the upgrade query, every `ClientMessage` (limits from
   `NET_LIMITS`), `PresenterControls`; type-tested against `contracts/net.ts`. `room-logic.ts`: room code / host key
   generation, timing-safe compare, token bucket (5/s, burst 10, strikes → 1008), presence from attachments
   (host excluded), ctl merge with `seq+1`, poll create/close, vote tally, message → effects reducer, expiry/alarm
   decision, room-size cap. Tests: `tests/worker/room-logic.test.ts`, `room-schemas.test.ts`.
2. **DO + routes** — `room.ts` I/O glue: hibernation (`acceptWebSocket`, `serializeAttachment`, ping/pong
   auto-response), welcome, sync, coalesced presence (≤ 1 Hz, timer only while dirty, skipped if unchanged),
   poll tally (≤ 2 Hz), SQLite votes, persisted ctl/poll, 12 h alarm (re-armed lazily on activity), bounded room
   (close 4503), pv mismatch 4400, bad host key 4401, unknown private room 4404. `routes/rooms.ts`: RL_ROOMS,
   code retry ×3, `/ws/:code` validation + 426, `/r/:code` 302. Tests: `room-do.test.ts` (fake state/sockets),
   `room-routes.test.ts` (Hono `app.request` with fake bindings).
3. **live-lab feature** — ROOM service (partysocket reconnect 0.5–8 s ×1.5, heartbeat, close-code stop list),
   roles from flags (`?screen=1` creates a room, `?room=` joins, else `LIVE`), `/api/time` first fix + WS
   NTP-style sync (min-RTT of best 3 of last 16, first fix jumps, then ≤ 5 ms slew) → `clock.setOffset`, `pick` on
   `sim:vehicle`/`sim:suspension` (trailing throttle), `store.room` status, presence chip + distribution bar overlay
   (design tokens, no per-frame work). Tests: `tests/features/live-lab-time-sync.test.ts`,
   `live-lab-presence.test.ts`; e2e `06-01-live.spec.ts` (offline in e2e mode: no errors, service present).
4. **Smoke + deploy** — `scripts/smoke-room.mjs <base> [--load N]`: two viewers (presence 2, dist update on pick),
   clock-sync sanity (offset vs `/api/time`, both clients agree), host ctl + audience vote on a created room,
   forbidden/validation checks, optional load. Run against `vite preview`, then `npx wrangler deploy` from a green
   build and run against production.
