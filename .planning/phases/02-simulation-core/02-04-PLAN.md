# 02-04 PLAN — Simulation facade, GT coupe, integration

**Objective:** replace the phase-1 stub with the real simulation (§7.6): the GT coupe drives the proving loop on the
02-01 speed profile, its three suspensions are solved by the 02-02 tables and its body/wheels move with the 02-03
ride model. Deliver honest-difference evidence for the three suspension types and keep the placeholder renderer working.

(stub that throws), `src/sim-core/content/gt-coupe.ts`, delete `src/sim-core/stub/**`, `src/features/{car,track}/index.ts`

deleted circle and goes with it (reported).

## Tasks
1. **Car model + Simulation** — `VehicleModel` seam (§7.2.4), `createCarModel` (tables cached per vehicle × linkage,
   ride params from the vehicle's shared targets + per-type extras, per-corner road envelope relative to the local
   plane, bank/grade-corrected specific forces, RC/anti-pitch inputs, steering via `rackForSteer`, grip use, events
   with 0.5 s hysteresis, interpolated TRUE + amplified POSE sample, rest pose), `createSimulation` (time, profile,
   path interpolation, seek pre-roll, setSuspension/setVehicle, events), moto stub. Tests: `simulation.test.ts`.
2. **GT coupe + content contributions + arch tests** — `gt-coupe.ts` (§7.5, geometry from `GT_GEOMETRY`, ARB tuned
   for DW 1.0–1.2 °/g incl. tyre compliance), `car`/`track` features contribute, `no-id-branching`, `content-copy`.
3. **Golden + no-alloc + integration report + e2e** — `golden.test.ts` (seed 42, 10 s, quantised hash),
   `no-alloc.test.ts` (10 000 steps + 1 000 samples, identity-stable, heap < 64 KB), `simulation-differences.test.ts`
   (the honest-difference table over one lap), `02-04-sim.spec.ts` (carousel camber ordering, live placeholder).
