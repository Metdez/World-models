# 02-01 PLAN — Track builder, road surface, speed profile

**Objective:** the pure, deterministic proving loop of ARCHITECTURE §7.2.1 / §7.5: `buildTrack(def) → BuiltTrack`
(closed clothoid/arc/line plan, analytic `roadHeight(s, l)`), the `provingLoop` content, and
`buildSpeedProfile(track, limits, dragArea, mass) → SpeedProfile` (forward/backward friction-ellipse profile,
`stateAt`, `timeAtS`). Reimplemented from research 11 §A/§C and 05 §5 (algorithm only; no GPL/LGPL code).

**Owns:** `src/sim-core/track/**`, `src/sim-core/path/**`, `src/sim-core/content/proving-loop.ts`,
`tests/sim-core/track*.test.ts`, `tests/sim-core/path*.test.ts`, `tests/fixtures/02-01-*.ts`.
Reuses `src/sim-core/math/{interp,rng}.ts` (01-02). `index.ts` is NOT touched (02-04 exports `buildTrack`).

## Tasks
1. **Plan geometry** — `track/closure.ts` (integrate primitives into dense node arrays s/x/y/ψ/κ/κ' at ≤ 0.25 m,
   per-step Simpson, exact 2×2 closure solve on the two named lines), `track/build.ts` (`buildTrack`: sections,
   props, `sectionIndexAt`, `sample` = node + local Simpson, `lineOffset`, `toWorld`), `path/path.ts`
   (cosine-knot driving line), `content/proving-loop.ts` (§7.5 table) + `tests/sim-core/track.test.ts`
   (closure < 1 mm / 1e-6 rad, solved lengths > 50 m, total 1.3–1.7 km, clearance ≥ 30 m, κ continuity,
   arc-length accuracy, no digits in names/captions).
2. **Road surface** — `track/iso8608.ts` (seeded periodic sum-of-cosines, 2 cm LUT, 3 lateral rails),
   `track/features.ts` (closed-form bump/pothole/kerb-strike/washboard/pave/humps/vertical-curve),
   `track/surface.ts` (macro elevation = swell + vertical curves, bank ramps, roughness class blend, features)
   + `tests/sim-core/track-surface.test.ts` (finite, deterministic, periodic, smooth in class-A/B sections,
   feature amplitudes, lateral bands, crest |a_z| ≤ 0.6 g, ISO RMS).
3. **Speed profile** — `path/speed-profile.ts` (0.5 m grid, line curvature κc + l'', v_lim, 2× backward/forward
   with friction ellipse + drag, 10 m smoothing, re-clamp, 8 Hz-equivalent low-pass of ax/ay, t(s), `stateAt`,
   `timeAtS`), fixture `tests/fixtures/02-01-gt-limits.ts` + `tests/sim-core/path-speed-profile.test.ts`
   (lap 65–85 s, |ay| ≤ lateral +1 %, ax within limits, ellipse, periodic, pure, `timeAtS∘stateAt` ±1 ms).
