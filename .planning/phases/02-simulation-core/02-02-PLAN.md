# 02-02 PLAN — Kinematics solver and three car suspensions

**Objective:** one generic rigid-upright solver (ARCHITECTURE §7.2.2, research 03 §3) driven by declarative
`AxleLinkage` data; reproduce the Chrono reference values (§7.3) before any content exists; precompute a
travel x rack lookup table with allocation-free `sample()`; measure the GT geometry from the DB11 GLB; ship
three physically plausible sports-car definitions (front + rear each) sharing wheel centre, track, tyre and
static alignment, and report every metric honestly against the §7.4 gates.

**Owns:** `src/sim-core/kinematics/**`, `src/sim-core/content/susp-*.ts`, `src/sim-core/content/gt-geometry.ts`,
`tests/sim-core/kinematics*.test.ts`, `tests/sim-core/db11-fit.test.ts`, `tests/fixtures/02-02-*.ts`.
**Depends on:** 01-02 math (`vec3`, `quat`, `mat`, `linsolve`, `interp`).

## Tasks
1. **Solver + metrics, TDD against Chrono** — `kinematics/lm.ts` (LM, central-difference Jacobian, warm start,
   step acceptance, no allocation), `kinematics/spatial.ts` (compile `AxleLinkage` → residuals: `distance`,
   `strut` with upright-fixed perpendicular basis, travel row; steer point displaced by rack; arm/link point
   placement), `kinematics/metrics.ts` (camber, toe, contact patch, solution twists from the implicit-function
   theorem → instant centre, roll-centre line, steer axis/KPI/caster/scrub/trail, anti-pitch).
   Fixtures `tests/fixtures/02-02-chrono-*.ts` (Chrono BSD-3 sets + opensus expected values);
   `tests/sim-core/kinematics-reference.test.ts` asserts the §7.3 table.
2. **Table** — `kinematics/table.ts`: `solveAxleKinematics` (continuation grid, travel 2.5 mm × rack 2 mm,
   curves, summary, `sample` bilinear no-alloc, `rackForSteer`, `rollCentreHeight(tl, tr)`, `antiPitch`).
   `tests/sim-core/kinematics-table.test.ts`: no NaN on the grid, residual < 1e-9 at every node, mirror symmetry,
   continuity, smooth curves, dense off-grid sweep, no-alloc `sample`, timing (table build, sample, warm solve).
3. **GT geometry + three definitions + gates** — `db11-fit.test.ts` measures wheelbase/track/tyre radius/wheel
   centre height from the GLB → `content/gt-geometry.ts`; `susp-macpherson.ts`, `susp-double-wishbone.ts`,
   `susp-multilink.ts` (seeded from Chrono topology/proportions, fitted to the GT car; copy without digits);
   `kinematics-gates.test.ts` prints the metric table and asserts the gates/orderings that plausible geometry
   meets; any discrepancy is reported in the SUMMARY instead of contorting geometry.

## Verification
`npx vitest run tests/sim-core/kinematics* tests/sim-core/db11-fit.test.ts` and `npm run check`, real output in SUMMARY.
