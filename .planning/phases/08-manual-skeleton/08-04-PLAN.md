# 08-04 PLAN — Manual chase camera

**Objective:** one camera rig, two target providers (ARCHITECTURE-M2 §10.3, research m2/08 §3). Auto keeps its exact
M1 code path; outside auto a manual provider predicts the target heading from velocity direction, yaw rate and steer
(the future path is unknown); Auto↔Manual cross-fades the TARGETS over 0.8 s; hard cut only on a `cut` mode change, a
`reset` drive event or an anchor jump > 15 m. World-up, no shake/roll/vignette/blur; FOV widening = the existing small
speed-linked CHASE FOV range. All manual thresholds are estimates in one `MANUAL` constant block.

**Owned:** `src/features/camera/**`, `tests/features/camera.test.ts`, `tests/e2e/08-04-camera.spec.ts`.

## Task 1 — provider + blend + tests
- `camera/manual.ts`: `MANUAL` constants, `manualHeading(drive, yawRate, steer, L)` (slip window, w_vel smoothstep,
  lead clamp, continuous 1.5° dead zone), `dampRamp` / `dampAngleRamp` (exact for piecewise-linear targets → frame-rate
  independent while the target moves), soft heading-lag limit.
- `rig.ts`: `mix` (0 auto … 1 manual) eased over `MANUAL.blendS`; mix = 0 runs the unchanged M1 code; otherwise a blended
  car frame (anchor = lerp(path point, (drive.x, drive.y, smoothed bodyPosition.z)), heading wrap-lerp), chase steps
  toward the blended target, eye ≥ `world.sample(eye).h + 0.7` (blended with the auto clearance). `cut()`; anchor jump
  > 15 m snaps; director shots refused (and cleared) outside auto; reduced motion → mode switches cut.
- `index.ts`: `drive:mode` with `cut` / `drive:event` reset → `rig.cut()`; reduced-motion flag per frame.
- Tests (synthetic frames + `withFakeDrive`): target maths (slip window, lead clamp, reverse = heading, standstill
  stable, dead zone), 0.8 s blend weight + no jump across the switch, hard cuts, 30/60/144 Hz ±1 cm after 2 s, ground
  clearance from `world.sample`, spin/slide/reverse smoothness, shots refused, explore/close-up in manual, no allocation.
- Verify: `npm run check`.

## Task 2 — e2e
- `tests/e2e/08-04-camera.spec.ts`: `?drive=manual`, `__app.driveIntent()`; held steer 2 s → angle(camera→car, heading)
  < 25°; reverse 2 s → still behind; explore/close-up still work; 3 screenshots. Runs only when the real plant exists
  (`drive().available`); otherwise skips with a reason. Private build/port, config.json restored.
