# 08-02 PLAN — Manual plant v0 on the loop (sim-core)

**Objective:** the visitor drives the SAME car: a 14-DOF plant (planar X, Y, yaw + the unchanged ride7dof + 4 wheel
spins) inside the car model, on an analytic GroundWorld (loop corridor + terrain), driven by a HumanDriver from latched,
quantised intents. Auto stays byte-for-byte M1 (goldens), Manual is stable at standstill / creeping / reversing / full
lock / kerbs / hard stops / wheelspin, and engaging from `stateAt(t)` is continuous. Binding: ARCH-M2 §7.1–7.4, 7.7
(v0), 7.9 (no countersteer help), 7.10 A/D/E, 7.12, 8.1 (loop + terrain).

## Tasks
1. **Det kernels + world** — `math/det.ts` (fdlibm-family ports, Cody–Waite reduction ≤ 2^20·π/2), `world/terrain.ts`
   (M1 terrain maths with det kernels), `world/project.ts` (warm-started Newton + windowed/global strided fallback),
   `world/ground.ts` (loop corridor bands, terrain blend, `loopSurface`). Tests: `det-math` (≤ 1 ulp grids + edge
   cases), `world-ground` (projection vs brute force, corridor = roadHeight, bands, terrain = M1 `groundHeight`),
   arch `det-math` + `no-type-tuning`.
2. **Plant** — `drive/{types,tyre,powertrain,human-driver,events,control,plant}.ts`, content
   `gt-coupe-{handling,tyres,powertrain}.ts` + `gt-coupe.handling`, car-model core extraction (writeCorners,
   rideParams, install keep), `ride7dof` export/importState, `vehicle-models` (`plant?`, `setSuspension(keep)`),
   `simulation` wiring (drive, world, detached clock, seek/setVehicle release, suspension swap keeping state).
   Tests: `drive-plant` (scripted 60 s, launch 10 s, 0–100, braking, skidpad lateral g, fuzz), `human-driver`,
   `handoff` (H1 at 20 lap times × 3 suspensions), `plant-standstill` (S1 v0).
3. **Auto fill + checks** — Auto CornerFrame fx/fy/capacity/omega/surface and `frame.drive`; goldens unchanged;
   no-alloc tripwire on the plant step; plant step cost printed.

## Verification
`npm run check` (typecheck, depcruise, vitest incl. M1 goldens); measured values copied into the SUMMARY.
