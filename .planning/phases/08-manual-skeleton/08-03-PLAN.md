# 08-03 PLAN — Take the wheel (drive feature v1)

## Objective
The takeover moment: a visitor presses W / ↑ / ← / → / ↓ / Enter while the car laps and drives it; R resets, Enter (or the
pill, or 12 s idle; 30 s on the presenter screen) hands back. A persistent AUTO | MANUAL pill (speed + gear in Manual),
a control hint that appears on takeover and fades, an idle cue, one polite announcement per mode change. Motorcycle:
"Auto only for this vehicle". Bound by ARCH-M2 §9, §10.1–10.2 (keyboard only; Enter = `drive:request {auto, immediate}`),
research m2/07, m2/22, m2 SUMMARY orchestrator decisions 1 and 5.

## Tasks
1. **DRIVE service + keyboard + pill/hint/idle** (`src/features/drive/**`, `tests/features/drive.test.ts`)
   - `keys.ts` (pure): `KeyboardEvent.code` → intent table, which codes a keydown captures per mode (Auto: W + arrows
     only; A/S keep M1 meanings), takeover codes.
   - `arbiter.ts` (pure): sources → one intent; most recent deliberate input wins with 1 s hysteresis; `fresh` only on a
     rising edge while armed; `disarm()` on hand-back, re-armed once every source is neutral.
   - `idle.ts` (pure): auto hint (4 s, shown 8 s), idle cue 3 s before hand-back, hand-back 12 s (×2.5 `?screen=1`).
   - `keyboard.ts`: held set (no repeats, tap latch so a sub-frame tap still takes over), cleared on blur /
     visibilitychange / contextmenu, text inputs ignored, preventDefault only in Manual, Enter/R commands.
   - `index.ts` + `drive.css`: service, pill (one toggle button, keyboard reachable, named), readout, hints, live region.
2. **controls/attract gating + e2e** (`src/features/{controls,attract}/**`, `tests/features/{controls,attract}.test.ts`,
   `tests/e2e/08-03-drive.spec.ts`)
   - controls `keyAction`: a/s/w/d → null outside Auto; Live chip while driving = immediate release; help card shows
     driving keys; bottom-centre stack reserves the pill row (`--sl-hud-drive-h`).
   - attract: never starts (idle or store flag) unless `driveMode === 'auto'`; exits on a mode change.
   - e2e per ROADMAP-M2 08-03 row; screenshots.
