# 12-02 PLAN — Room driver role

**Objective:** one phone drives the big screen's car through the room DO (ARCH-M2 §12.2, research m2/17 §5, 14, 21),
without changing host/presenter/poll behaviour or the frozen contract (`src/contracts/net.ts`, protocol 3).

## Tasks
1. **Reducers + schemas** (`worker/room-logic.ts`, `worker/schemas/room.ts`, `tests/worker/room-{logic,schemas}.test.ts`)
   - `role=driver` upgrade (private rooms with a stored driver key only, else 4401) → pending until `{t:'auth',k}`
     matches the driver key (timing-safe) → attach + welcome + `replace-driver` effect (older drivers close 4409).
   - Rate lanes: `general` (5/s, burst 10), `driver` (90/s, burst 30; every frame of a driver socket), `tel`
     (5/s, burst 5; a screen's `tel` only). Frame cap per role: driver 128 B, others 1024 B (→ 1009).
   - `in` (authenticated driver) → `relay-in` effect (`{...in, r: now}` to screens only); `tel` (screen) →
     `relay-tel` (driver only); from any other role → `err forbidden`. Strict zod schemas with integer ranges.
   - Presence counts `drivers` (authenticated), excluded from `viewers`; `samePresence` compares it.
2. **DO glue + route + smoke** (`worker/room.ts`, `worker/routes/rooms.ts`, `scripts/smoke-room.mjs`,
   `tests/worker/room-{do,routes}.test.ts`)
   - `init(hostKey, driverKey)`; route returns `driverKey`. Sockets accepted with a role tag
     (`acceptWebSocket(ws, [role])`), relay targets come from `getWebSockets('screen' | 'driver')` (hibernation-safe,
     no full scan, never `broadcast`). Sender attachment cached in a WeakMap. No new timers, no storage on the drive path.
   - Smoke: driver scenario — wrong key 4401, host key as driver key 4401, LIVE driver 4401, pending `in` forbidden,
     60 Hz × 30 s stream with per-frame relay latency (p50/p95/max) and zero drops, audience + viewer receive 0 `in`,
     `tel` screen → driver, viewer `in` forbidden, newer driver replaces older (4409), presence drivers 1 → 0.

## Verification
`npm run check`; `npx vitest run tests/worker/room*`; `node scripts/smoke-room.mjs http://localhost:<port>` against a
private `vite preview`; deploy from a private worktree (only if production == a commit our worktree contains), then
`node scripts/smoke-room.mjs` against production.
