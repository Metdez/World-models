# 12-04 PLAN — Phone driver

**Objective:** the presenter's big screen (`?screen=1`) shows a "Drive from your phone" QR; the phone opens
`/remote.html?room=CODE#d=<driverKey>` in driver mode (touch slider + GAS/BRAKE by default, optional tilt) and drives
the screen car through the room as the DRIVE source `'phone'` (no bypass of conditioning/aids). Fails safe.
Bound by ARCH-M2 §12.3, research m2/17, 12-02 hand-off. Worker untouched.

## Tasks
1. **live-lab key + phone-drive (screen side).** `room-service.ts` keeps `driverKey` from `CreateRoomResponse` (stored
   with the screen room) and exposes it on ROOM. `src/features/phone-drive/`: pure `link.ts` (u32 seq order, one-packet
   interpolation from `r` spacing, 250 ms decay over 300 ms / 1 s lost timeline, link level amber > 150 / red > 250 ms
   frame age, `tel` packing), `index.ts` (screen only, not e2e: QR card, `'phone'` source via DRIVE, failsafe →
   `drive:request auto` + "Controller lost" banner, presence `drivers` drop = lost, f-bit-1 falling edge = hand back,
   link badge + "Driven from a phone" note, `tel` 5 Hz with k bits from `strike` / `slide` events). Inert without a
   room or driver.
2. **Remote driver panel.** `src/remote/driver-*.ts`: `#d=` key → sessionStorage, fragment scrubbed; driver socket
   (`role=driver`, `auth` first frame on every open, final closes 4401/4409/4404 → calm recovery screens); landscape
   panel: relative-drag wheel slider + GAS/BRAKE, optional tilt (permission requested synchronously in the tap,
   2-tap calibration: Centre + Turn right, gravity `atan2(x, y)`, dead zone 3°, lock 35°, exponent 1.4, One-Euro
   1.5 Hz / 0.01), 30 Hz + pedal edges, skip when `bufferedAmount > 0`, wake lock (re-acquired on visibility), `tel`
   speed/gear + `navigator.vibrate` on k bits, link badge from 1 Hz `sync` RTT + `tel` age. Pure tests for tilt
   maths (synthetic gravity: portrait/landscape, both rotations, neutral, sign learning), filter, frame packing.
3. **E2E.** `tests/e2e/12-04-phone.spec.ts`: private build + `vite preview` (workerd), screen `?screen=1&quality=low&debug=1`
   + phone (touch, 844×390): QR card, phone pairs, touch input moves the screen car (`source` phone, steer sign),
   measured input latency, closing the phone → Returning within 1.5 s + banner; second phone → first sees "replaced";
   wrong key screen; bundle has no three.js. Screenshots to the scratchpad.
