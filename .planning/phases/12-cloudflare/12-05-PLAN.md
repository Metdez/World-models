# 12-05 PLAN — Server-shared replays (client)

**Objective:** a run that does not fit in a `#r=` link (or any run, on request) can be saved to `POST /api/replays`
(12-01, live) behind a Turnstile check and shared as a short `#rid=` link; opening one fetches and plays it exactly like
a fragment replay. Turnstile loads only when the user chooses to save. Every failure is calm and specific and the
fragment link (whole run ≤ 60 s, else the last minute) stays offered. ARCH-M2 §12.1, ROADMAP-M2 12-05.

**Owned files:** `src/features/replay/**`, `tests/features/replay.test.ts`, `tests/e2e/12-05-share.spec.ts`.

## Tasks
1. **Pure modules** — `turnstile.ts` (public site key `0x4AAAAAAGLbvJGTqk052mg6`; Cloudflare test keys on
   localhost only, `?turnstile=pass|fail` there; on-demand loader of `api.js?render=explicit`, retried after a failure),
   `server.ts` (`#rid=` parsing and id check, save data = base64url(deflate-raw(encodeReplay)), the save span (whole
   run ≤ 600 s, else / when over `REPLAY_API.maxBytes` the last ten / five / two / one minutes), `saveReplay` and
   `loadSaved` with injectable fetch → typed error values: offline, challenge, busy, daily cap, storage, disabled,
   too large, failed; missing/expired, invalid id, damaged), copy in `copy.ts` (no digits). Unit tests.
2. **UI** — share popover gains "Save a short link" / "Save the whole run"; on click: the one privacy line, the widget,
   "Saving…", then the `#rid=` link in the same input with Copy; errors in the popover's status line with "Try again"
   when it can help; the fragment link stays. `#rid=` on load / hashchange: fetch → same play path ("Shared run",
   "Drive it yourself", older-model label). Popover anchored to the right while driving (chips at the right edge).
3. **e2e** (`12-05-share.spec.ts`, private build + preview with the real worker, local D1 and the test secret; test
   site keys): real save of a > 60 s run → `#rid=` → copy → open in a new page → plays to the identical end CRC;
   always-fail key; mocked 403 / 429 / daily cap / storage / disabled / offline; unknown id 404; older-model link.
   Screenshots to the session scratchpad `shots/12-05-*.png`.
