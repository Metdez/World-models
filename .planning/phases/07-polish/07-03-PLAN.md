# 07-03 PLAN — Accessibility, reduced motion, audio

## Objective
Every HUD control works from the keyboard with a visible focus ring and a name; screen readers hear captions and
option changes only (never per-frame numbers); reduced motion turns off fly-throughs, trails and idle attract;
HUD text stays ≥ 4.5:1 over the bright sky; touch targets ≥ 44 px on touch devices and the HUD works at 1024×768.
Stretch: the `audio` feature — muted by default, M / HUD button, persisted, nothing before a user gesture, silent in
attract unless the presenter's screen has sound on.

## Tasks
1. **Audio** (`src/features/audio/**`): pure mapping functions (`mix.ts`: engine rate/gain from speed + throttle
   with pseudo gears per vehicle class, skid gain from grip use, thump gain from bump-stop / travel-rate spikes,
   bounded; ramps via `setTargetAtTime`), a WebAudio graph built once on the first unmuting gesture (two engine
   loops crossfaded by class, skid loop, master gain; one-shot impact + synthesized UI tick on events), mute button
   placed in the HUD Display group (own fallback pill if controls is off), M key, localStorage. Unit test
   `tests/features/audio.test.ts`.
2. **A11y + reduced motion** (`src/ui/**`, controls, insights, attract, telemetry-panel, engineer, credits CSS):
   insight live region announces the caption once (chip updates silent); canvas stage gets role img + live label;
   attract does not idle-start under reduced motion; loading fade honours reduced motion; `prefers-contrast: more`
   tokens; coarse-pointer 44 px minimums for every small HUD target; glass backing strong enough over the sky
   (measured); 1024×768 layout fixes found by screenshot.
3. **E2E** `tests/e2e/07-03-a11y.spec.ts`: Tab walk reaches every visible interactive HUD element once and each
   has a name, radiogroups are one tab stop with arrow keys; reduced-motion emulation (store flag, CSS durations
   0, attract not started); contrast sampled from a screenshot behind HUD text; touch 1024×768 target sizes;
   mute toggle (M + button, persisted, no AudioContext before a gesture). Screenshots `07-03-*.png`.

## Files
