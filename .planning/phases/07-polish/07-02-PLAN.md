# 07-02 PLAN — Delivery hardening

Freeze on `worker/**`, `wrangler.jsonc`, `public/_headers`, `vite.config.ts` (and, with care, contracts) lifted for this
plan by the orchestrator. Contract edits are mirrored in `.planning/ARCHITECTURE.md` (byte-compared by a test).
This plan may deploy (from a private worktree of a clean HEAD).

## Tasks
1. **Global engineer rate limit + daily budget** — `worker/limiter.ts`: one `Limiter` Durable Object (SQLite class,
   migration v2) named `engineer`: fixed 60 s windows per client id (6) and per address (40), counted for every
   request (valid or not) so a burst is refused wherever it lands; a UTC-day model-call budget (300 ≈ 6.6k of the
   10k free neurons) after which answers are the labelled rule answer. Replaces `RL_ENGINEER` and the per-isolate
   memory limiter. Proof: `scripts/smoke-engineer-limit.mjs` against production (invalid bodies: no neurons spent).
2. **Host key out of the URL** — protocol v2: host connects without `k=`, sends `{t:'auth', k}` as its first frame;
   welcome follows auth; wrong key → 4401. Cheap gaps: `hosts` count in presence ("host connected"); `poll: null`
   on a closed poll clears it (remote gets a Clear button). Screen→host state echo deferred.
3. **CSP enforced** in `public/_headers`, verified with zero `securitypolicyviolation` on follow/close-up/engineer/
   remote (`tests/e2e/07-02-delivery.spec.ts`).
4. **Bundle split** — lazy chunks for heavy feature code where the feature module boundary allows; report sizes.
5. **Production proofs** — redirects keep query + fragment, immutable hashed assets, `/api/*` uncached.
6. **Leftovers** — regenerate `tests/fixtures/06-02-telemetry-carousel.json` from the sim; COMPONENT_COLORS comment.
