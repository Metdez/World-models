# 10-02 PLAN — GroundWorld zones and proving-ground content

**Objective.** The proving-ground annex north of the loop as pure sim-core content: zones (spurs, apron, links, ride
street, dynamics pad, braking platform) composed into the 09-04 GroundWorld (global projection, blended terrain) so
`sample` returns h / base / surface per wheel and `terrainHeight` adds the field and zone skirts. ARCH-M2 §8.1, §8.3;
research m2/11. The loop's own road surface stays bit-identical (no world = the 09-04 code path untouched).

**Owned files.** `src/sim-core/world/{zones,ground}.ts`, `src/sim-core/content/proving-ground.ts`,
`tests/sim-core/{world-zones,proving-ground}.test.ts`, `tests/arch/world-copy.test.ts`.

## Tasks
1. **Zones + composition** (`world/zones.ts`, `world/ground.ts`): compile rect/path zones (path = `integratePlan` nodes at
   0.25 m, projected like the loop), zone-local (u, w), eased linear base, features (M1 `featureHeight`), seeded
   ISO 8608 roughness (one periodic LUT seeded from the world-id hash, per-zone offset), patches; 20 m grid cull;
   priority composition with a 0.5 m smoothstep edge band OUTSIDE each footprint (abutting zones never dip); the loop
   corridor below; terrain = 09-04 blended terrain → field flattening (smoothstep over `blend`) → zone skirts. Zones
   reaching within 60 m of the loop centreline (the spurs) take the loop's base plane near it (smoothstep |l| 18→60),
   so the spur meets the loop without a step. `inBounds` = loop |l| ≤ 60 ∪ field + 40 ∪ 30 m of a zone. Zero
   allocation in `sample`; no transcendental `Math.*`.
2. **Content + tests** (`content/proving-ground.ts`, tests): §8.3 table verbatim where it holds (spur arc = exact
   π/2 − 0.6; spawns moved to ≥ 10 m from the zone's start edge where §8.3 put them 4–5 m in), stations, cones (slalom 7,
   ISO 3888-2 18), circle, signs. Tests: spur ends (1 cm / 0.01°), annex clearance ≥ 40 m from the loop centreline
   except spurs (against the real loop), priority / patches / split-μ per wheel, roughness seeded from the id,
   continuity on a 0.25 m grid (0.1 m steps; 2 cm) over field and spur joins, field/skirt terrain, inBounds, spawns,
   no-alloc, loop bit-identical with/without the world, plant drive across each spur (no NaN, road-input step ≤ 3 cm),
   world copy (no digits, no suspension ranking, approximate-grip wording).
