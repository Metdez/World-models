# 03-03 PLAN — DB11 visual + vehicle-view runtime

**Objective:** the `db11` VehicleVisual (premium materials, correct placement, wheels posed from the solved
CornerFrame, x-ray ghost) contributed by the `car` feature, and the `vehicle-view` runtime that loads the current
vehicle's visual, pre-builds every suspension visual of that vehicle (hidden, compiled), toggles them on
`sim:suspension`, fades x-ray from `store.xray` (0.4 s) and routes `highlight` with a timeout.

**Owned files:** `src/features/car/**`, `src/features/vehicle-view/**`, `tests/features/vehicle-view.test.ts`,
`tests/e2e/03-03-car.spec.ts`.

## Tasks
1. **DB11 visual** (`car/db11/`): GLTFLoader + MeshoptDecoder; root rotation +π/2 about Y (glTF +Z forward → three
   +X); placement measured from the tyre meshes (front wheel centres at x = cgToFront, wheel-centre height = tyre
   radius); geometry baked into the car frame (dequantised) and merged per OUR material (draw-call budget ≈ 30);
   one hub group per corner found by position (rim + tyre + disc spin, caliper steers/cambers only); hide stock
   suspension stand-ins, the duplicate disc, duplicate V8 engine, coincident signal meshes and small badges;
   re-material all 53 GLB materials (clearcoat metallic paint with procedural object-space flakes, tinted glass,
   rubber, machined rims, chrome, lights with emissive DRL/tail); x-ray = screen-door dither of body materials +
   additive fresnel ghost shell (GLSL, tested in the browser). GLB disc/caliper tagged
   `userData.replacedBySuspension` so vehicle-view hides them when a suspension visual is mounted.
2. **vehicle-view runtime**: pure-ish runtime (`runtime.ts`) + feature wiring; works with zero suspension visuals;
   compile with everything forced visible and x-ray at 1 so neither a swap nor the first x-ray compiles shaders;
   disposal on vehicle change; no per-frame allocation.
3. **Tests + e2e**: node tests (material table covers the GLB, bake/merge, runtime toggling/fade/highlight with
   fakes); e2e: tyre contact patches on the road, wheel/hub poses equal CornerFrame poses, zero errors/warnings,
   screenshots (3/4 front, side, rear, top, front wheel at full lock in the hairpin, x-ray).

**Verification:** `npm run check`, `npm run build`, `npm run e2e`, screenshots inspected.
