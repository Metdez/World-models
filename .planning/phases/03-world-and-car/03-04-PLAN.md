# 03-04 PLAN — kit3d part helpers + procedural `spatial-linkage` suspension visual

**Objective:** shared three.js part helpers (`src/kit3d/**`) and the `linkage-parts` feature that contributes the
`spatial-linkage` SuspensionVisual: every car suspension (MacPherson, double wishbone, 5-rod multi-link) drawn as
engineered parts built ONCE from the definition's hardpoints and moved per frame from `CornerFrame.points` only
(rigid 3-point frames, unit tubes, telescoping damper, shader-driven constant-wire-radius spring). Zero per-frame
allocation. Research 22 B0–B7, 10 §B10, palette `COMPONENT_COLORS` (contract).

**Owned files:** `src/kit3d/{tube,rigid,spring,damper,hull,brake,materials}.ts`, `src/features/linkage-parts/**`,
`tests/features/kit3d.test.ts`, `tests/features/linkage-parts.test.ts`, `tests/e2e/03-04-parts.spec.ts`.

## Tasks
1. **kit3d** — `tube.ts` (unit cylinder/sphere, `updateTube`, `bakedTube`), `rigid.ts` (`frameFrom3`, `setRigid`,
   A-arm geometry with bushings/ball-joint housing/gusset), `spring.ts` (aT/aPhi geometry, `onBeforeCompile`
   GLSL + matching depth material, TS mirror `springVertex` of the same closed form, coil-bind clamp), `damper.ts`
   (body from the lower mount, rod from the upper mount, fixed lengths), `hull.ts` (inflated ConvexGeometry +
   creased normals), `brake.ts` (drilled disc + hat, caliper), `materials.ts` (role materials from
   COMPONENT_COLORS + rubber/steel/chrome/brake, emissive highlight). Node tests: wire radius constant across
   lengths (TS mirror), coil bind, frameFrom3 maps rest→now exactly, no NaN.
2. **linkage-parts** — `layout.ts` (pure: parts from constraints/members/roles/uprightPoints/spring/ARB mount +
   point indices by name), `corner.ts` (three objects for one corner from its rest points), `axle.ts` (rack, ARB
   torso), `index.ts` (contribute `spatial-linkage`; `update` reads `CornerFrame.pointOrder/points`, resolves
   indices only when `pointOrder` changes; `setHighlight` by role × corner; `dispose`).
3. **Tests + e2e** — node: builds for all 3 definitions, update from kinematics-table samples (static, bump, droop,
   ±lock, both sides mirrored) without NaN, links keep length, spring wire radius constant, no allocation in
   `update`, capsule clearance between parts (and a tyre proxy) at bump/droop/lock. e2e spec: app boots healthy
   with the feature on (visual is mounted by 03-03's vehicle-view). Throwaway harness (scratchpad, not committed)
   for the screenshots `03-04-<type>-<pose>.png`.

**Verification:** `npx vitest run tests/features/kit3d.test.ts tests/features/linkage-parts.test.ts`,
`npm run check`, `npm run build`, harness screenshots inspected (no shader errors/warnings).
